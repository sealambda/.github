# Support

This page lists the routes to get help in a repository of the Sealambda
organization that has no `SUPPORT.md` of its own. Links are absolute, because
GitHub shows this file in other repositories.

- **Something does not work as documented:** open the issue form **Bug
  report** on the **New issue** page of the repository.
- **A feature or a change:** open the issue form **Feature or change
  request**.
- **A question:** the organization has no separate channel for questions. Open
  an issue with the form that fits best and write the question in it.
- **A vulnerability:** never use a public issue. Follow the
  [security policy](https://github.com/sealambda/.github/blob/main/SECURITY.md).
  If the repository accepts no private reports, open the issue form
  **Request a security contact**.
- **A contribution:** read the
  [contributing guide](https://github.com/sealambda/.github/blob/main/CONTRIBUTING.md).
