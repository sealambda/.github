# Support

Use these routes to get help in a Sealambda repository that has no `SUPPORT.md`
of its own.

<!-- The links are absolute because GitHub shows this file in other
repositories. -->

- **Something does not work as documented:** open the **Bug report** issue form
  on the **New issue** page of the repository. A repository with its own issue
  templates or `config.yml` shows those and not this form. Use the one that fits
  best.
- **A feature or a change:** open the **Feature or change request** issue form,
  or the template of the repository that fits best.
- **A vulnerability:** never use a public issue. Follow the
  [security policy](https://github.com/sealambda/.github/blob/main/SECURITY.md).
- **A contribution:** read the
  [contributing guide](https://github.com/sealambda/.github/blob/main/CONTRIBUTING.md).
