# Support

Use these routes to get help in a Sealambda repository that has no
`SUPPORT.md` of its own.

<!-- The links are absolute because GitHub shows this file in other
repositories. -->

- **Something doesn't work as documented:** open the **Bug report** issue
  form on the **New issue** page of the repository.
- **A feature or a change:** open the **Feature or change request** issue
  form.
- **A question:** open an issue with the form that fits best and write the
  question in it.
- **A vulnerability:** never use a public issue. Follow the
  [security policy](https://github.com/sealambda/.github/blob/main/SECURITY.md).
- **A contribution:** read the
  [contributing guide](https://github.com/sealambda/.github/blob/main/CONTRIBUTING.md).
